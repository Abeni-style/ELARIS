ELARIS

Ethiopian Local Airline Reservation and Information System

ELARIS is a Python-based airline reservation project developed as a team project during school in Kallamino Special High School.

Overview

The project explores how a simple airline reservation system can help users interact with flight information and booking features.

Built With

- Python

Team

Developed collaboratively by a team of six students during AddisCoder.

Our team earned 1st place for the project.

Purpose

ELARIS was an opportunity to apply programming concepts, collaborate with other students, and turn an idea into a working software project.

Status

Educational project developed during school.
